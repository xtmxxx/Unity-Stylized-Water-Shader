# Stylized Water Shader для Unity URP

Стилизованный шейдер воды для мобильных платформ на Unity URP

## Особенности
Вертексная анимация волн
- Глубина воды с плавным переходом цвета
- Рефракция (искажение объектов под водой)
- Пена на пересечениях с объектами

## Требования
- Unity 6000.0.58f2
- URP (Universal Render Pipeline)
- Target platform: Android

## Установка
1. Клонируйте репозиторий
2. Откройте проект в Unity
3. Выберите Plane из Hierarchy
4. Настройте параметры в Inspector

## Параметры

Основные цвета и глубина (Depth & Color)

- Depth Fade Distance: Дистанция смешивания цветов. Определяет, насколько плавно мелкая вода переходит в глубокую

- Shallow Color: Цвет воды у берега (на мелководье)

- Depth Color: Цвет воды на глубине

Рефракция (Refraction)

- Use Refraction: Глобальный переключатель (Switch). Позволяет полностью отключить искажения для оптимизации на слабых устройствах

- Refraction Strength: Интенсивность искажения объектов под водой

- Refraction Speed: Скорость анимации искажений

- Refraction Scale: Масштаб (тайлинг) шума рефракции

Пена (Foam)

- Foam Texture: Текстура шума, которая используется для генерации пены

- Foam Color: Цвет пены (обычно белый или светло-голубой)
  
- Foam Amount: Общее количество пены и её плотность

- Foam Cutoff: Жесткость краев пены (порог отсечения)

- Foam Scale: Размер паттерна пены на поверхности

- Foam Speed: Скорость движения пены по поверхности воды

Волны и рябь (Waves & Ripples)

- Wave Height: Максимальная высота вертикального смещения волн (Vertex Displacement)

- Wave Speed: Общая скорость движения волн

- Ripple Strength: Сила визуальной ряби (Normal Map) на поверхности

- Ripple Tiling: Плотность мелкой ряби (X, Y)

- Ripple Speed / Ripple Speed_1: Скорости наложения слоев ряби для создания хаотичного движения воды

- Color Ripple: Влияние движения волн на изменение оттенка воды
